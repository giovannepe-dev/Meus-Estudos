# ESGFlow — Dashboard de Sustentabilidade e ESG

> Projeto desenvolvido com auxílio de IA (Lovable) como parte do meu aprendizado em desenvolvimento frontend.

## Sobre o Projeto

Dashboard de monitoramento de indicadores ESG (Ambiental, Social e Governança) com visualização de dados de CO₂ evitado, matriz energética e relatórios de sustentabilidade.

## Funcionalidades

- Dashboard com indicadores ESG em tempo real
- Card de CO₂ evitado
- Gráfico de matriz energética
- Relatório de sustentabilidade energética
- Gauge visual de desempenho ESG
- Sidebar de navegação

## Como Rodar Localmente

```bash
git clone https://github.com/giovannepe-dev/esgflow.git
cd esgflow
npm install
npm run dev
```
