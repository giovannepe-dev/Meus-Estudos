# App Tela Corporativa — Painel Administrativo Empresarial

> Projeto desenvolvido com auxílio de IA (Lovable) como parte do meu aprendizado em desenvolvimento frontend.

## Sobre o Projeto

Painel administrativo empresarial com controle de acesso por perfil (roles), proteção de rotas e gerenciamento de leads em período de trial. Inclui suporte a PWA para instalação no celular.

## Funcionalidades

- Autenticação com rotas protegidas
- Sistema de permissões por perfil (RoleGuard)
- Painel de leads durante período de trial
- Layout administrativo responsivo
- PWA instalável no celular
- Build para APK Android (Bubblewrap)
