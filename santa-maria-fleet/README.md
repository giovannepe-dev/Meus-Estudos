# Santa Maria Fleet — Sistema de Gestão de Frotas

> Projeto desenvolvido com auxílio de IA (Lovable) como parte do meu aprendizado em desenvolvimento frontend.

## Sobre o Projeto

Sistema de gerenciamento de frotas de veículos com lembretes de agendamento, indicador de conectividade online/offline e suporte a PWA para uso em campo mesmo sem internet.

## Funcionalidades

- Gestão de veículos e agendamentos
- Lembretes de reserva
- Indicador de status online/offline em tempo real
- Layout de app com navegação lateral
- PWA instalável, funciona offline
