# SM Patrimônio — Sistema de Gestão de Patrimônio

> Projeto desenvolvido com auxílio de IA (Lovable) como parte do meu aprendizado em desenvolvimento frontend.

## Sobre o Projeto

Sistema de gerenciamento de patrimônio com importação de itens, notificações em tempo real e suporte a PWA. Voltado para controle de bens e ativos de empresas.

## Funcionalidades

- Cadastro e importação de itens patrimoniais
- Notificações com sino de alertas
- Layout responsivo com navegação lateral
- PWA instalável no celular, funciona offline

## Como Rodar Localmente

```bash
git clone https://github.com/giovannepe-dev/smpatrimonio.git
cd smpatrimonio
npm install
npm run dev
```
